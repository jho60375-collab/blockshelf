# BLOCKSHELF

Furniture library with 522 black SVG previews and 519 downloadable DWG files.

GitHub Pages deploys the site/ directory. The workflow builds the full-library ZIP
from the DWG files before publishing, then checks every preview and download path.
The ZIP is generated during deployment so no file exceeds GitHub's Git file limit.

Missing source DWGs: HEB 02 - Table, Nest - Table, Proto - Chair In.
